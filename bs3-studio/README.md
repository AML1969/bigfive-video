# BS Profiler 3.1 — характеристика личности по видео: Big Five, MBTI, эмоции, голос, мимика, речь

Отдельный проект рядом с BS 2.0: свой пакет `bs3`, своя команда `bs3`, свой порт **7880** (у 2.0 — 7870), порт
предпросмотра **7882**, свои рабочие папки `~/bs3_data/{web_jobs,pool,logs,gradio_tmp}` и своя
временная папка Gradio (`GRADIO_TEMP_DIR=~/bs3_data/gradio_tmp`). Из пакета `bs2` ничего не импортируется (это
проверяет `tests/test_isolation.py`). Общие с 2.0 только тяжёлые ресурсы, которые читаются, но не меняются: окружение
`~/bs/venv`, веса OCEAN-AI в `~/bs/models`, чекпоинты модели AMLAI 1.0 в `~/bs/mm_runs_seeds`, кэши Hugging Face и
Ollama. Обе версии можно запускать одновременно.

## Что нового в 3.1

- **Одна модель на анализ.** Вместо выбора языка речи на странице выбирается модель: `OCEAN-AI` (веса MuPTA) или
  `AMLAI 1.0` (собственная модель, построенная по рецепту MM-PSYCHE и обученная на First Impressions V2; внутренний
  ключ `mm`). Загружается и работает только выбранная модель (`Studio.backend(member)` собирает бэкенд одного
  участника), вторая «для второго мнения» не запускается — на видеокарте одна модель Big Five, обработка быстрее.
- **Только русская речь.** Языка речи на странице нет: `lang="ru"` закреплён в пайплайне (`bs3.LANG`) и по умолчанию
  в командной строке. Whisper распознаёт русский; OCEAN-AI берёт веса MuPTA; AMLAI 1.0 переводит транскрипт на
  английский внутри себя, как и раньше.
- **result.json.** `model.selected` (`oceanai` | `mm`), `model.selected_title` («OCEAN-AI» | «AMLAI 1.0»),
  `model.primary` = выбранная модель; в `variant_scores` только она; `traits` — её оценки. Раздел `mbti` —
  schema_version 3: `source` и `model` называют эту модель, полей `second` и `agreement` больше нет.
- **Старые задания открываются.** `scores.clean_view` берёт модель, записанную в задании (`selected`, для заданий
  3.0 и перенесённых из 2.0 — `primary`, то есть OCEAN-AI), и оставляет в представлении только её — по ролику и по
  отрезкам; метка «собеседование» (есть только у AMLAI 1.0) из представления OCEAN-AI убирается вместе со второй
  моделью, а оговорка о ней (C2) стоит только там, где метка показана — под полосками оценок и в PDF задания
  AMLAI 1.0. Сохранённые разделы `mbti` схем 1 и 2 не показываются, тип пересчитывается при показе.
- **result.json без сводки 2.0.** Поле `narrative` больше не пишется (3.x показывает «Как получены оценки»);
  `modalities_used` называет, на что смотрела модель (`audio, video, text` у OCEAN-AI; `face, audio, text,
  behavior` у AMLAI 1.0), и так же читается строка «Модальности» приложения А в PDF; у метки «собеседование» для
  русской речи только оценка, без процентилей. В работающем сервере при переключении модели прежняя выгружается
  (`Studio._evict`), Whisper передаётся следующему анализатору, а не загружается второй раз.
- **PDF без почти пустой последней страницы.** Короткий транскрипт (до 30 мм) не открывает страницу сам по себе:
  таблицы приложения А ужимаются, чтобы он остался на их странице, а если и так не помещается — приложения
  начинаются с новой страницы вместе (`pdf_report._appendix_layout`).
- **Журнал** пишет выбранную модель в строке «СТАРТ» и итог одной модели в строке «РЕЗУЛЬТАТ», без второго мнения.
- **Объяснения** (ключевые кадры, вклад модальностей, слова) есть только у AMLAI 1.0 и строятся для неё всегда;
  галочки «Объяснения» на странице больше нет. Для задания OCEAN-AI вкладка «Объяснения» показывает одну фразу
  («Модель OCEAN-AI не строит объяснений…»), в PDF та же фраза стоит одной строкой под разделом «Голос и речь», а
  раздела «Что повлияло на оценку…» нет.
- **Одна модель на экране и в PDF.** Блок «Оценки по чертам» без рамки второго мнения; вкладка «Тип MBTI» — одна
  панель и одна лента по отрезкам с названием модели («OCEAN-AI, веса MuPTA» или «AMLAI 1.0»), без строки согласия;
  «Как читать тип MBTI» без абзацев о двух системах; на вкладке «Данные» — «Модель и время обработки» в одну строку;
  в PDF — строка «Модель» в паспорте, раздел 2 с одной строкой типа, таблицей осей без столбца согласия и одной
  лентой, приложение А без строки «Язык речи». Все «своя модель», «MM-PSYCHE» в текстах заменены на «AMLAI 1.0»
  (рецепт MM-PSYCHE назван один раз в «Как получены оценки»).
- **Первый экран.** «Характеристика личности» — компактное окно высотой в левую колонку (видео, модель, кнопки) с
  вертикальной прокруткой текста внутри (`webapp.APP_CSS`, класс `bs3-char`); «Ключевые факты» — строкой карточек
  под верхней парой, так что вкладки видны без прокрутки страницы.

## Что было в 3.0

- **Характеристика личности** в главном окне: связный текст по пяти чертам Big Five, типу MBTI и нейротизму,
  с наблюдениями за поведением на записи. Текст строится по шаблонам и словарю `bs3/config/lexicon_ru.json`,
  без языковой модели: один результат — всегда один и тот же текст.
- **Перевод шкал Big Five в нотацию MBTI** (экстраверсия → E–I, открытость опыту → S–N, доброжелательность → T–F,
  добросовестность → J–P) с уверенностью по каждой оси, пограничными осями (X), ближайшим типом и альтернативами;
  нейротизм — отдельной строкой. Тип по ходу ролика — буквенная лента по отрезкам.
- **Абсолютная шкала.** Буквы MBTI считаются ровно по формуле документа заказчика на собственной оценке системы
  от 0 до 1: граница 0.5 по каждой оси, пограничная зона 0.15 (буква X в записи с учётом границ), уверенность
  |v − 0.5| / 0.5 — одинаково для любой из моделей. Уровни черт — пять полос той же шкалы, согласованных с
  пограничной зоной: 0.80 и выше — высокий, 0.65–0.79 — выше среднего, 0.36–0.64 — средний, 0.21–0.35 — ниже
  среднего, 0.20 и ниже — низкий (границы — в `bs3/scores.py`). Оценка округляется один раз, до двух знаков, и
  уровень, буква и пограничность решаются по этому напечатанному числу, поэтому одно и то же значение везде выглядит
  одинаково. Ни с какой группой обработанных роликов оценки не сравниваются; полоски обзора показывают только саму
  оценку.
- **Чистые оценки.** Оценки — только той модели, которая работала, по отрезкам, где она дала оценку; отрезки без
  оценки показаны пропусками, а не смешаны с другой шкалой.
- Новая вкладка «Тип MBTI» и раздел PDF «Тип MBTI (перевод шкал Big Five)»: тип по осям с уверенностью и тип по ходу
  ролика (в 3.0 там стояли рядом типы двух систем; с 3.1 — одна модель).

Система не ставит психологических диагнозов: это кажущаяся личность по первому впечатлению, а тип MBTI — запись
четырёх шкал Big Five в другой нотации, а не результат опросника.

## Установка и запуск (WSL)

```bash
~/bs/venv/bin/pip install --no-deps -e /mnt/c/Users/nrsmh/OneDrive/Documents/AMLAI/cloude_projects/code/BS/bs3-studio
bash bs3-studio/scripts/run_web3.sh               # веб: http://localhost:7880 (лог ~/bs3_data/logs/web.log)
pkill -f "bs3 web"                                # остановить
bash bs3-studio/scripts/run_preview.sh ~/bs3_data/web_jobs/<задание>   # предпросмотр готового задания на :7882
~/bs/venv/bin/python bs3-studio/tests/run.py      # тесты (только стандартная библиотека)
```

`--no-deps` обязателен: зависимостей в `pyproject.toml` нет, а общий venv с 2.0 не должен обновляться. Без установки
можно запустить так: `PYTHONPATH=bs3-studio ~/bs/venv/bin/python -m bs3.cli web --port 7880`.

Юнит systemd `deploy/bs3-web.service` написан, но не включён: включается только решением владельца.

## Структура

```
bs3/__init__.py      версия и название продукта (PRODUCT, PRODUCT_SLUG), модели (MODEL_TITLES, DEFAULT_MODEL), язык (LANG)

bs3/charts.py        графики plotly для веба и PNG (matplotlib) для PDF
bs3/webapp.py        интерфейс Gradio
bs3/pdf_report.py    PDF-отчёт
scripts/             run_web3.sh, run_preview.sh, import_job.py, rerender_samples.py, check_job.py, add_mbti.py, selftest.py
tests/               run.py и тесты (изоляция, MBTI, чистые оценки)
deploy/              bs3-web.service
```

## Оговорки

Модели эмоций, голоса и выражений обучены на англоязычных корпусах и фотографиях: их выходы — сигналы о поведении на
видео, относительные и не откалиброванные для русскоязычных людей. Big Five — кажущаяся личность по первому
впечатлению; метка «собеседование» (есть только у AMLAI 1.0) — не рекомендация о найме. За один анализ работает одна
модель, и её результат — одно описание. Модели обучены на разных данных и работают на разных шкалах: OCEAN-AI (веса
MuPTA) обычно даёт 0.65–0.80 по O, C, E, A, AMLAI 1.0 — 0.3–0.45, поэтому по формуле с границей 0.5 первая чаще даёт
ENFJ или X на части осей, вторая — I, S, T, P или X. Если один ролик обработан обеими моделями, это два разных
описания, и напрямую сравнивать их не следует.
