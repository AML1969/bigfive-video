# BS Profiler 3.0 — характеристика личности по видео: Big Five, MBTI, эмоции, голос, мимика, речь

Отдельный проект рядом с BS 2.0: свой пакет `bs3`, своя команда `bs3`, свой порт **7880** (у 2.0 — 7870), порт
предпросмотра **7882**, свои рабочие папки `~/bs3_data/{web_jobs,pool,logs,gradio_tmp}` и своя
временная папка Gradio (`GRADIO_TEMP_DIR=~/bs3_data/gradio_tmp`). Из пакета `bs2` ничего не импортируется (это
проверяет `tests/test_isolation.py`). Общие с 2.0 только тяжёлые ресурсы, которые читаются, но не меняются: окружение
`~/bs/venv`, веса OCEAN-AI в `~/bs/models`, чекпоинты своей модели в `~/bs/mm_runs_seeds`, кэши Hugging Face и
Ollama. Обе версии можно запускать одновременно.

## Что нового в 3.0

- **Характеристика личности** в главном окне: связный текст по пяти чертам Big Five, типу MBTI и нейротизму,
  с наблюдениями за поведением на записи. Текст строится по шаблонам и словарю `bs3/config/lexicon_ru.json`,
  без языковой модели: один результат — всегда один и тот же текст.
- **Перевод шкал Big Five в нотацию MBTI** (экстраверсия → E–I, открытость опыту → S–N, доброжелательность → T–F,
  добросовестность → J–P) с уверенностью по каждой оси, пограничными осями (X), ближайшим типом и альтернативами;
  нейротизм — отдельной строкой. Тип по ходу ролика — буквенная лента по отрезкам.
- **Абсолютная шкала.** Буквы MBTI считаются ровно по формуле документа заказчика на собственной оценке системы
  от 0 до 1: граница 0.5 по каждой оси, пограничная зона 0.15 (буква X в записи с учётом границ), уверенность
  |v − 0.5| / 0.5 — для обеих систем и обоих языков. Уровни черт — пять полос той же шкалы, согласованных с
  пограничной зоной: 0.80 и выше — высокий, 0.65–0.79 — выше среднего, 0.36–0.64 — средний, 0.21–0.35 — ниже
  среднего, 0.20 и ниже — низкий (границы — в `bs3/scores.py`). Оценка округляется один раз, до двух знаков, и
  уровень, буква и пограничность решаются по этому напечатанному числу, поэтому одно и то же значение везде выглядит
  одинаково. Ни с какой группой обработанных роликов оценки не сравниваются;
  для русской речи полоски обзора показывают только саму оценку, для английской — ещё процентиль норм First
  Impressions V2.
- **Чистые оценки.** Для русской речи основная оценка — только OCEAN-AI по отрезкам, где она работала; отрезки без
  неё показаны пропусками, а не смешаны со шкалой своей модели.
- Новая вкладка «Тип MBTI» и раздел PDF «Тип MBTI (перевод шкал Big Five)»: там, и только там, типы двух систем
  стоят рядом, с согласием по осям; в тексте характеристики системы не сравниваются.

Система не ставит психологических диагнозов: это кажущаяся личность по первому впечатлению, а тип MBTI — запись
четырёх шкал Big Five в другой нотации, а не результат опросника.

## Установка и запуск (WSL)

```bash
~/bs/venv/bin/pip install --no-deps -e /mnt/c/Users/nrsmh/OneDrive/Documents/AMLAI/cloude_projects/code/BS/bs3-studio
bash bs3-studio/scripts/run_web3.sh               # веб: http://localhost:7880 (лог ~/bs3_data/logs/web.log)
pkill -f "bs3 web"                                # остановить
bash bs3-studio/scripts/run_preview.sh ~/bs3_data/web_jobs/<задание>   # предпросмотр готового задания на :7882
~/bs/venv/bin/python bs3-studio/tests/run.py      # тесты (только стандартная библиотека)
```

`--no-deps` обязателен: зависимостей в `pyproject.toml` нет, а общий venv с 2.0 не должен обновляться. Без установки
можно запустить так: `PYTHONPATH=bs3-studio ~/bs/venv/bin/python -m bs3.cli web --port 7880`.

Юнит systemd `deploy/bs3-web.service` написан, но не включён: включается только решением владельца.

## Структура

```
bs3/__init__.py      версия и название продукта (PRODUCT, PRODUCT_SLUG) — единственный источник
bs3/pipeline.py      Studio (модели) и run_analysis: Big Five по отрезкам + дополнительные анализы + тексты
bs3/scores.py        чистые оценки (clean_view) и уровни черт на шкале 0…1 (границы полос — здесь)
bs3/mbti.py          перевод Big Five в нотацию MBTI, согласие систем, тип по отрезкам, раздел mbti
bs3/config/          mbti.json (пороги 0.5, названия типов), lexicon_ru.json (словарь характеристики)
bs3/analyses/        emotions_text.py, emotions_voice.py, face_expr.py, speech_stats.py
bs3/charts.py        графики plotly для веба и PNG (matplotlib) для PDF
bs3/webapp.py        интерфейс Gradio
bs3/pdf_report.py    PDF-отчёт
scripts/             run_web3.sh, run_preview.sh, import_job.py, rerender_samples.py, add_mbti.py, selftest.py
tests/               run.py и тесты (изоляция, MBTI, чистые оценки)
deploy/              bs3-web.service
```

## Оговорки

Модели эмоций, голоса и выражений обучены на англоязычных корпусах и фотографиях: их выходы — сигналы о поведении на
видео, относительные и не откалиброванные для русскоязычных людей. Big Five — кажущаяся личность по первому
впечатлению; метка «собеседование» — не рекомендация о найме. Две системы обучены на разных данных и работают на
разных шкалах: OCEAN-AI (веса MuPTA) на русской речи обычно даёт 0.65–0.80 по O, C, E, A, своя модель — 0.3–0.45,
поэтому по формуле с границей 0.5 первая чаще даёт ENFJ или X на части осей, вторая — I, S, T, P или X. Типы двух
систем показаны рядом, а не усреднены.
