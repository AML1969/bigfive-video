# BS — Big Five по видео (версия 1.0)

Локальный конвейер «видео → пять черт личности»: загрузили ролик, где человек говорит в камеру, получили оценки
открытости опыту, добросовестности, экстраверсии, доброжелательности и эмоциональной стабильности, метку
«пригласить на собеседование», описание поведения, транскрипт, объяснения и PDF-отчёт. Всё считается на своей машине
(WSL2 + GPU + локальная Ollama), без внешних сервисов. Интерфейс и отчёты на русском; поддерживаются английская и
русская речь.

*English summary.* A fully local "video in → Big Five out" pipeline modelled on MM-PSYCHE (LEYA-HSE, IEEE Access 2026):
OCEAN-AI pretrained weights (FIV2 / MuPTA) + our own MM-PSYCHE-style fusion model trained on First Impressions V2,
averaged into an ensemble (mACC 0.9274, CCC 0.733 on the full FIV2 test split). CLI, Gradio web UI with explanations,
PDF export, long-video segmentation, Russian and English speech. Documentation is in Russian.

## Что внутри

| Часть | Что делает |
| --- | --- |
| OCEAN-AI (готовые веса) | аудио + видео + текст → Big Five; веса для английской речи (FIV2) и русской (MuPTA) |
| Своя модель (рецепт MM-PSYCHE) | лицо (CLIP), голос (CLAP), речь и описание поведения (EmoRoBERTa) → графовый фьюжн → 5 черт + «собеседование»; обучена нами на FIV2, среднее пяти запусков |
| Ансамбль | английский: среднее двух систем; русский: основная оценка OCEAN-AI MuPTA, своя модель как второе мнение |
| Объяснимость | вклад модальностей, ключевые кадры, слова речи и описания, пояснение простыми словами |
| Интерфейсы | CLI `bs infer / explain / infer-dir / eval-fiv2 / web`, веб на Gradio, экспорт в PDF, пакетная обработка папки |

## Точность (test First Impressions V2, 1997 клипов)

| Система | mACC | CCC |
| --- | ---: | ---: |
| OCEAN-AI, веса FIV2 | 0.9255 | 0.703 |
| Своя модель, среднее 5 seed | 0.9202 | 0.715 |
| **Ансамбль OCEAN-AI + своя модель (по умолчанию)** | **0.9274** | **0.733** |
| MM-PSYCHE, однозадачная модель из статьи | 0.918 | 0.740 |

Метка «собеседование»: ACC 0.922, CCC 0.762. На русскоязычных роликах точность не измерена: размеченных русских данных
в открытом доступе нет, см. `report.md`, части 1.8 и 3.

## Быстрый старт

Требования: Windows 11 с WSL2 Ubuntu 24.04, NVIDIA GPU (проверено на RTX 5090 Laptop, 24 ГБ), Ollama на Windows с
моделью `qwen2.5vl:7b`. Установка и запуск описаны в [bs/README.md](bs/README.md); кратко:

```bash
bash bs/scripts/setup_wsl.sh                       # окружение ~/bs/venv (torch cu130, oceanai, transformers 4.45.1 ...)
~/bs/venv/bin/pip install -e ./bs
~/bs/venv/bin/bs setup-weights --lang all          # веса OCEAN-AI
# веса своей модели: из релиза v1.0 распаковать в ~/bs/mm_runs_seeds/seed*/best.pt
~/bs/venv/bin/bs infer video.mp4 --lang ru --out result.json
bash bs/scripts/run_web.sh 7860                    # веб: http://localhost:7860
```

В скриптах `bs/scripts/*.sh` пути к проекту заданы для машины разработки (`/mnt/c/Users/nrsmh/...`) — при переносе
поправьте переменную с путём в начале скрипта.

## Данные и веса, которых нет в репозитории

- Видео FIV2: зеркало Hugging Face `yeray142/first-impressions-v2` (CC BY-NC 4.0); разметка, транскрипты и описания
  поведения — CSV из репозитория MM-PSYCHE.
- Веса OCEAN-AI скачиваются командой `bs setup-weights`.
- Веса своей модели (5 чекпоинтов по 24 МБ) — в релизе v1.0 этого репозитория; обучены на FIV2, поэтому только для
  исследовательского и некоммерческого использования.
- Сторонние репозитории (MM-PSYCHE, OCEAN-AI, SSL-MEPR) не вложены, ссылки в `LICENSE`.
- Личные ролики и отчёты по ним не публикуются.

## Ограничения

Система оценивает *кажущуюся* личность по первому впечатлению, как её воспринимают посторонние наблюдатели; это не
психологическая диагностика. Метка «собеседование» — не рекомендация о найме. Для русской речи две системы дают оценки
на разных шкалах (подробности в `report.md`); откалибровать их без русскоязычной разметки нельзя.
